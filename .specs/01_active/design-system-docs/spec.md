What:
Rebuild the Figma documentation for `Blog Design System v1.0` into a single
shareable, recruiter-readable narrative page (`📚 Design system`) ordered from

The previous structure was drifted and ambiguous (`📚 Docs`, stale legacy page
references, and non-responsive "mobile" views). A clean and verified docs page
lets collaborators and agents reason about the system quickly, map design
decisions to shipped code, and avoid writing to dead nodes or outdated masters.
